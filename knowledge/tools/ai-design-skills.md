Open-source collection of design skills for AI coding tools (Claude Code, Cursor, Codex, Windsurf and anything that reads a markdown rules file) by Elaya. Each skill is a self-contained folder. The author used the landing-page skill with Higgsfield, Claude and Cursor to design a batch of landing pages in two months. About 15k stars.

## Key Features

- `landing-page-design`: builds a landing page from scratch with intake questions, page structure, conversion copy and a visual system (type, spacing, radius, motion)
- `figma-designer`: designs inside Figma with variables, named text styles, auto layout and components with every state
- Install with `npx skills add elayadesign/ai-design-skills` (skills CLI), or copy SKILL.md manually
- Design values live in one section near the bottom of each skill, so forking and editing tokens is easy
- MIT licensed; companion redesign-skill repo for upgrading existing sites
