LVGL (Light and Versatile Graphics Library) is a free, MIT-licensed embedded UI library in portable C for devices from small MCUs to 3D-capable MPUs, with no external dependencies. Chip vendors (NXP, Espressif, Renesas), RTOS projects (Zephyr, NuttX) and board makers already integrate it. A typical UI needs about 100kB RAM and 200-300kB flash.

## Key Features

- 30+ built-in widgets (button, label, slider, chart, keyboard, arc, table) and a style system with 100+ properties
- Flexbox and grid-like layout engines, data bindings, and support for mouse, touchpad, keypad, encoder input
- Built-in 2D renderer with gradients, anti-aliasing, opacity, shadows; works with monochrome, e-paper, OLED, TFT displays
- LVGL Pro: editor, Figma integration, online viewer and CLI that exports pure LVGL C code from XML (free for non-commercial use)
