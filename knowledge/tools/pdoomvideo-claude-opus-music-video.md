Source code for a second Claude Opus 5.5 music video for "I'm Upping My P(doom)", painted frame by frame with p5.js and p5.brush. The README documents two generations of work, both in Claude Code, and includes Opus's own storyboard and animation guide used to brief parallel subagents.

## Key Features

- Nine chapters as separate source files, with shared code for the Clawd character, props, lyrics and timeline.
- render.mjs paints frames in headless Chrome (resumable, multi-worker) and encodes the MP4 with ffmpeg.
- STORYBOARD.md and ANIMATION_GUIDE.md show how the model planned and briefed its subagents.
