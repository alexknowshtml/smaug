Peach is a local-first video metadata scraper and media manager (AGPL-3.0, Python and React, ~14.7k stars). It recognizes video codes, reads NFO files and fills in titles, performers, studios and covers from multiple sources while preserving manual edits. It is 18+ oriented; the tweet flagged it NSFW and called it the best project of the week.

## Key Features

- Metadata scraping from multiple sources with NFO support
- Unified browsing of local drives, SMB, mounted cloud storage and PikPak libraries
- Playback with subtitles, speed control, resume and timeline previews
- Performer/creator follow tracking and a want list
- Cloud download via video code search or magnet links
- Tag, duplicate, version and part management; metadata and history stored locally
- Task center for background jobs; Windows, macOS, Docker/NAS and source installs
