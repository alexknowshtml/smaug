A starter kit with code, instructions and assets for animating a hand-painted cartoon character in p5.js and p5.brush with Claude Opus 5.5. It is derived from the P(doom) music video code and an analysis of what the model did and did not do well.

## Key Features

- Includes the Clawd character with 31 acted emotions and model sheets.
- ANIMATION_GUIDE.md gives the model rules (handmade, alive, transitions always, something happens in every scene).
- `node render.mjs --clip` renders an 11-second demo; tips on prompting, storyboards and reasoning level (tested on xhigh).
