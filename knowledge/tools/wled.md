A fast, feature-rich ESP32 firmware for controlling addressable LEDs over WiFi, from simple WS2812B strips to large 2D matrices and HUB75 panels. Originally created by Aircoookie and now community maintained.

## Key Features

- 200+ built-in effects, 50+ palettes with a custom palette editor, audio-reactive effects, and 2D matrix support
- Segments with independent effects, and up to 250 presets with playlists
- Up to 17 LED outputs on ESP32; supports WS2812B, WS2811, WS2815, SK6812, APA102 and RGBW/CCT strips
- WLED app for Android and iOS, JSON and HTTP APIs, MQTT with Home Assistant discovery, E1.31/Art-Net/DDP, ESP-NOW sync, Alexa, Hue sync
- OTA updates, multi-WiFi with AP fallback, Ethernet support on many boards
