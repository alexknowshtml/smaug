A toolbox of film styles made in code for Claude Code. Each style is a style prompt plus a demo film made entirely in code by Claude Opus 5.5 with no video model; you pick a style (or define your own), bring a story, and let the coding agent direct. By Lemomo.

## Key Features

- 66 ready-to-use film styles per the README, each with a demo short film.
- Style groups include Evidence Films, Edit and Documentary styles, and a "make a style your own" flow.
- Packaged as a Claude Code skill/plugin; uses ffmpeg, canvas, WebGL and Three.js under the hood.
