A growing collection of viral videos made with Claude Opus 5.5, each with the prompt its creator shared (or the original post where no prompt was published). Every video was produced by asking the model to write the animation as code (HTML, Canvas, SVG, Three.js and similar).

## Key Features

- Videos grouped into motion graphics, explainers, 3D scenes and games/interactive pieces, plus a "latest prompts" section.
- Copy-ready prompts per video, with links to the original X posts.
- Side-by-side comparison with live remakes on Skillry (README cites 418 videos).
