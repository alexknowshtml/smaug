A collection of skills for AI agents and chatbots from Jane Street. Each skill is a directory containing a `SKILL.md` file with instructions for the agent. The repo had about 1,730 stars at bookmark time.

## Key Features
- socratic-tutor skill: turns an LLM into a strict personal tutor using the Socratic method
- Starts with a diagnostic, then builds a skill map with levels 0-5
- Asks one question at a time, with spaced review and a final assessment
- Works with coding agents supporting the SKILL.md format (copy the directory into the skills folder, say "teach me X")
- Works with plain chatbots by pasting the SKILL.md body into the chat or a system prompt
