A Chinese-language collection of copy-ready prompts and public cases for having Claude Opus 5.5 make videos by writing code (Canvas, p5.js, Three.js, Remotion, Manim, Blender scripts, rendered via headless browser and FFmpeg). Per the README it holds 18 full prompts and 54 public cases across 9 technical routes, covering the first week after launch (2026-09-22 to 09-25).

## Key Features

- Quick-start: Claude Code on Opus 5.5 at high/xhigh effort, plus Node.js, Chrome and FFmpeg.
- Only author-published prompts are included, each linked to its source post.
- Notes on strengths (motion graphics, explainers, lyric MVs) and weaknesses (photoreal footage).
