A generative, code-rendered music video for "I'm Upping My P(doom)" with word-synced karaoke typography, made with Claude Opus 5.5 in Claude Code. Every frame is a deterministic function of song time, so the browser preview and the offline 1080p60 or 4K60 export are identical.

## Key Features

- TypeScript and three.js renderer (bun + Vite) with post-processing such as bloom, halation and grain.
- Python (uv) analysis tools for Demucs stem separation, forced alignment cross-checked with Whisper, and beat/onset analysis.
- Offline renderer drives headless Chrome and ffmpeg; docs cover the treatment and engine API.
