Open-source catalog of cybersecurity skills for AI coding agents (Claude Code, Cursor, Codex) by Bri Russell, announced by her husband Corey Haines after a large update. Skills are authored as Claude Code SKILL.md files, built into Cursor and Codex adapters, and installable via `npx skills` or the Claude Code plugin marketplace. The pitch is that the agent does the heavy lifting while the user supplies stack context, serving everyone from pentesters to founders without a CISO.

## Key Features

- `security-start` triage skill that asks a few questions and picks the right skill
- Code and dependency audits: `owasp-audit`, `api-audit`, `dependency-audit`, `patch-sweep`, `scanner-pipeline`, `finding-triage`
- Cloud and infra: `cloud-audit`, `iam-audit`, `container-audit`
- Response and monitoring: `incident-triage`, `disk-forensics`, `malware-triage`, `log-watch`, `security-comms`
- Operator and compliance skills: `personal-opsec`, `threat-modeling`, `privacy-engineering`, `hipaa-audit`, `pci-audit`, `control-audit`, `agent-supply-chain-audit`
- Offensive skills (recon, osint-recon, web-pentest, red-team) for engagements
