Open-source collection of SKILL.md-format skills from Ilias Ism that let Claude Code, Cursor, Codex and other agents run SEO and AI-answer-engine optimization work: daily site health checks, title-tag rewrites, blog refreshes with SERP gap analysis, backlink planning, customer-journey mapping and conversion copywriting. Installed via `npx skills add Illyism/seo-skills`. MIT licensed, about 728 stars at bookmark time.

## Key Features

- seo-autopilot: daily agent covering site health checks, fixes, keyword map, articles, comparison pages, free tools, link drafts and AI answer tracking
- blitz-seo: 30-day sprint to rank one page for one money keyword
- seo-title-optimization and blog-refresher: rewrite titles/H1s and refresh posts using SERP gap analysis
- block-ai-scrapers: block AI coding agents and CLI scrapers while keeping verified Googlebot intact
- linkdr: managed backlink purchasing plan (promotes the author's LinkDR service)
- Content, marketing and copywriting skills: intro, scribiz (video transcripts to blog), customer-journey, diff-marketing (commits to changelogs/posts), blitz-copy, understand-customers
