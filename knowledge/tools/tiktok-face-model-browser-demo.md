A browser-based demo by @ayoships that runs on-device face models extracted from the TikTok app (ported from ByteNN) so anyone can see how TikTok scores a photo. For a face it outputs an attractiveness score, an age guess, a gender guess and a mood breakdown. Processing stays on the user's device. The author reports testing showed significant negative bias against darker skin and older faces.

## Key Features

- Upload a photo or try a sample; face is cropped and scored locally
- Outputs attractiveness score, age guess, gender guess, mood
- Option to pixelate the face and share a result card
- Follows an earlier "I reverse engineered tiktok" post by the same author
